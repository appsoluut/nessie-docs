# Typography migration

## How to migrate

Migrating typography tokens is as not straightforward by just matching names, as the correct mapping
depends heavily on the context in which a token is used.

To help you with this, the table below lists the old tokens alongside their possible new
counterparts. Note that one old token may correspond to multiple new tokens, or in some cases,
no direct mapping may be available.
